# Privacy Policy

Last updated: 25 August 2026

DynamicQRCodes is a local reference and validation tool for secure charging QR codes.

## Data collection

The app does not collect, transmit, sell or share personal data. It contains no analytics, advertising SDKs or user accounts and does not communicate with an application backend.

Configuration values, including the shared secret, remain in the app's volatile memory and are not persisted by the app. They are cleared when the app process ends.

The app stores only the current version and build identifier together with the date and time that build was first launched. This local technical metadata is used for the version footer, is refreshed after an app update and is not transmitted.

## Camera

Camera access is optional and used only while the QR-code scanner is visible. Camera frames are processed locally by Apple's AVFoundation framework to recognize QR codes. The app does not save or transmit camera images.

## Sharing and external links

The user can explicitly copy a generated URL to the system clipboard or open project, support and privacy links. Those actions are initiated by the user and handled by the operating system or selected website.
